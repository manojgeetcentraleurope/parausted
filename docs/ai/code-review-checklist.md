# AI Code Review Checklist — ParaUsted

Use this checklist when reviewing code generated by Copilot or any AI model.

## Database & Data

- [ ] Monetary amounts use INTEGER cents (not float/decimal)
- [ ] New tables have `merchant_id` column
- [ ] New tables have RLS policy (`ALTER TABLE ... ENABLE ROW LEVEL SECURITY`)
- [ ] `merchant_id` extracted from JWT/auth session, not from request body
- [ ] No raw SQL string concatenation (parameterized queries only)
- [ ] Voucher codes generated with `crypto.randomUUID()` or `crypto.randomBytes()`
- [ ] No UPDATE or DELETE on `ledger_entries`, `audit_events`, `security_events`

## API Routes

- [ ] Zod validation schema at the start of the handler
- [ ] Auth check: `supabase.auth.getUser()` before any data access
- [ ] Error responses are generic: `"Invalid or not found"` (no internal details)
- [ ] State changes create `audit_event` record
- [ ] Rate limiting applied (or documented as TODO for this endpoint)
- [ ] Correct HTTP status codes (200, 201, 400, 401, 403, 404, 429, 500)

## Security

- [ ] No `dangerouslySetInnerHTML`
- [ ] No `service_role` key in client-side code
- [ ] No PII in console.log or structured logs (emails/phones masked)
- [ ] No voucher codes logged in full (masked: `PU-****-****-X8Q1`)
- [ ] No secrets hardcoded (all from `process.env`)
- [ ] Input sanitized (HTML stripped from personal_message, names)

## Payments

- [ ] Voucher generated ONLY inside payment confirmation handler
- [ ] Webhook handler verifies Stripe signature
- [ ] Webhook handler checks `processed_webhooks` for idempotency
- [ ] Redemption uses `SELECT...FOR UPDATE` row lock
- [ ] `CHECK` constraints on redemption amounts (`> 0`, `balance_after >= 0`)

## TypeScript

- [ ] No `any` type (use proper types or `unknown` + type guard)
- [ ] No `@ts-ignore` without explanatory comment
- [ ] Proper error handling (try/catch, not swallowed errors)
- [ ] Correct import order (React → Next → external → internal → types)

## Conventions

- [ ] File names in kebab-case
- [ ] Component names in PascalCase
- [ ] Named exports (not default exports)
- [ ] Server components by default (`'use client'` only when needed)
- [ ] Tailwind CSS (no CSS modules or styled-components)
